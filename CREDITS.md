# Credits

This repository contains **no downloaded data**, only scripts that fetch it from
the public sources below. Fetched data stays on your own machine.

## Wikidata

Film metadata (titles, release years, genres, original languages and links to
Wikipedia articles) comes from [Wikidata](https://www.wikidata.org). Wikidata's
structured data is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain).

## Wikipedia

Film descriptions (article lead sections and plot summaries) come from
[English Wikipedia](https://en.wikipedia.org), written by Wikipedia's
contributors. The text is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Text shown or derived from it in this project is credited to Wikipedia and its
contributors. Each film keeps a link to its Wikipedia article, where the full
author history is available.
